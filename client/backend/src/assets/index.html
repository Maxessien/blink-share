Blink Escrow API

Off-chain indexing & metadata service for the Blink Share escrow program.

Service online
This service stores off-chain escrow briefs, milestones, and disputes, and cross-checks them against on-chain vault state. Writes require a wallet signature via the x-wallet, x-message, and x-signature headers.
Available endpoints
GET
/health
Liveness check.
GET
/escrows
List escrows (filter by status/address).
GET
/escrows/:vaultId
Get one escrow with milestones and disputes.
POST
/escrows
Create an escrow (signed).
POST
/escrows/:vaultId/accept
Worker accepts an escrow (signed).
POST
/escrows/:vaultId/milestones
Propose a milestone (signed).
PATCH
/milestones/:vaultId/:index
Update milestone status (signed).
POST
/disputes
Raise a dispute (signed).
GET
/disputes
List disputes (filter by resolved).
POST
/disputes/resolve
Admin resolves a dispute (signed).
